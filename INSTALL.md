# Инструкция по локальному развертыванию

Для запуска проекта на вашей машине должны быть установлены: **Python (версия 3.10 или выше)**, **PostgreSQL** и **Git**.

## Шаг 1. Клонирование репозитория
Откройте терминал и склонируйте проект на свой компьютер:
```bash
git clone https://github.com/EgorKomakov/ClinicService.git
cd ClinicService
```

## Шаг 2. Создание виртуального окружения
Создайте изолированное окружение для проекта и активируйте его:
```bash
python -m venv .venv
```

**Для macOS / Linux:**
```bash
source .venv/bin/activate
```

**Для Windows:**
```bash
.venv\Scripts\activate
```

## Шаг 3. Установка зависимостей
Установите все необходимые библиотеки из файла `requirements.txt`:
```bash
pip install -r requirements.txt
```

## Шаг 4. Настройка переменных окружения (.env)
В корне проекта создайте файл **`.env`** и добавьте в него строку подключения к вашей базе данных PostgreSQL, а также секретный ключ:

```env
DATABASE_URL=postgresql://postgres:ваш_пароль@localhost:5432/postgres
SECRET_KEY=любая-секретная-строка
```
*(Замените `ваш_пароль` на реальный пароль от вашей базы данных)*.

## Шаг 5. Инициализация базы данных и заполнение данными
Выполните скрипты по очереди, чтобы создать структуру базы данных, администратора, врачей и прайс-лист.

**1. Создание таблиц (если они еще не созданы):**
```bash
python -c "from app import app; from extensions import db; app.app_context().push(); db.create_all()"
```

**2. Создание аккаунта администратора (Логин: `admin`, Пароль: `admin`):**
```bash
python create_admin.py
```

**3. Добавление врачей и их расписания:**
```bash
python add_doctors.py
```

**4. Заполнение справочника услуг (Прайс-лист):**
```bash
python seed_services.py
```

## Шаг 6. Запуск приложения
Запустите Flask-сервер:
```bash
python app.py
```
После этого приложение будет доступно в браузере по адресу: **`http://127.0.0.1:5000`**

## Шаг 7. Запуск автоматических тестов (опционально)
В проекте реализовано 53 автотеста. Чтобы убедиться в работоспособности бизнес-логики, выполните:
```bash
pytest -v --cov=.
```
*(Тесты используют изолированную базу SQLite в памяти и не затронут ваши реальные данные в PostgreSQL).*
