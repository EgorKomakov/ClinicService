## 📖 О проекте
Данный репозиторий содержит исходный код выпускной квалификационной работы. 
Проект представляет собой полноценную клиент-серверную информационную систему для автоматизации работы частной клиники. 

В отличие от классических CRUD-систем, данное приложение включает в себя **мультимедийные технологии** и **игровые механики (геймификацию)** для повышения вовлеченности пациентов в процесс лечения.

### Ключевые фичи:
*   🖼️ **Мультимедиа:** Интерактивная галерея медицинских снимков (зум, панорамирование) и модуль записи аудиозаметок врача.
*   🎮 **Геймификация:** Система опыта (XP), уровней и достижений для пациентов (по фреймворку Octalysis) с защитой от накрутки баллов.
*   💳 **Биллинг:** Модуль назначения платных процедур и симуляции оплаты (Mock-платежи) с защитой от двойных транзакций.
*   🛡️ **Безопасность:** Гибридная модель разграничения доступа (RBAC + ReBAC), защита от IDOR-уязвимостей.

## 🛠️ Используемые технологии

**Backend:**
*   Python 3.12+
*   Flask (веб-фреймворк)
*   SQLAlchemy / Flask-SQLAlchemy (ORM)
*   PostgreSQL (СУБД)
*   Flask-Login (аутентификация)

**Frontend:**
*   HTML5 / CSS3 / Vanilla JavaScript
*   Bootstrap 5 (адаптивная верстка)
*   Vue.js (реактивность)
*   Viewer.js (интерактивный просмотр изображений)
*   MediaRecorder API (запись аудио в браузере)

**Тестирование и DevOps:**
*   Pytest / Pytest-cov (автотесты)
*   python-dotenv (управление секретами)

## 🏗️ Архитектура и методологии

*   **Архитектура:** Клиент-серверная (Client-Server).
*   **Паттерн:** MVC (Model-View-Controller), Модульный монолит (Modular Monolith).
*   **Методология разработки:** Итеративная (Iterative Development), TDD (Test-Driven Development).
*   **Тестирование:** Риск-ориентированное, интеграционное и модульное (Smoke + Unit + Integration).
